# Testing

## Setup

```powershell
# Activate the virtual environment (required once per terminal session)
.\.venv\Scripts\Activate.ps1

# Or use the full path without activating:
.\.venv\Scripts\python.exe -m pytest ...
```

## Test Files

### `test_question_smoke.py`
**Smoke tests** — verifies every question evaluates without raising an exception.

- `test_evaluates_without_error`: Runs `Question.eval()` with seed=42 and checks it doesn't crash and produces output.
- `test_has_check_fields`: Verifies the question has at least one answer check field (skips display-only questions).

Parametrized over all (question_id, language) pairs discovered from the repository.

### `test_question_answers.py`
**Answer correctness tests** — verifies question outputs match stored annotations (`test_annotations.json`).

- `test_num_checks_matches`: Number of check fields equals the annotation.
- `test_check_types_match`: Check field types (number, radio, fraction, canvas) match.
- `test_expected_answers_match`: Computed answer values match stored expected answers.
- `test_canvas_presence`: Canvas presence/absence matches annotation.
- `test_table_presence`: Table presence/absence matches annotation.

Only runs for questions that have a `test_annotations.json` file (generated by `tools/generate_test_annotations.py`).

### `test_question_browser.py`
**Browser tests** — uses Playwright to load questions in a real Chromium browser.

- `test_correct_answers_accepted`: Fills in correct answers and verifies JS validation passes.
- `test_no_js_errors_on_render`: Loads questions and checks no JavaScript console errors occur.
- `test_all_inputs_have_ids`: Verifies all input elements have proper IDs.

Requires: `playwright install chromium` and a running dev server (auto-started by fixture).

### `test_question_visual.py`
**Visual regression tests** — takes screenshots and compares against baselines.

Requires: Playwright + baseline screenshots (generated with `--update-snapshots`).

## Running Tests

```powershell
# Run all non-browser tests
pytest tests/ -p no:playwright

# Run smoke tests only
pytest tests/test_question_smoke.py -p no:playwright

# Run answer tests only
pytest tests/test_question_answers.py -p no:playwright

# Run browser tests (needs Playwright chromium installed)
pytest tests/test_question_browser.py
```

## Filtering Tests with `-k`

The `-k` flag filters tests by matching substrings against the full **test node ID**.

A test node ID looks like:
```
tests/test_question_smoke.py::TestQuestionSmoke::test_evaluates_without_error[data_2/q00001/rs]
```

It is composed of: `file::Class::method[parametrize_id]`

The parametrize ID is set by our test code as `category/question_id/language` (e.g. `data_2/q00001/rs`).

`-k` supports boolean expressions with `and`, `or`, `not`:

```powershell
# All tests for question q00001 in data_2 category
pytest tests/ -p no:playwright -k "q00001 and data_2"

# All tests for a specific language
pytest tests/ -p no:playwright -k "q00001 and data_2 and rs"

# Exclude a specific test type
pytest tests/ -p no:playwright -k "data_2 and not canvas"

# Multiple questions
pytest tests/ -p no:playwright -k "q00001 or q00002"
```

## Generating Annotations

```powershell
# Generate annotations for all questions (incremental — skips existing)
python tools/generate_test_annotations.py

# Regenerate all annotations from scratch
python tools/generate_test_annotations.py --force

# Generate for a single question
python tools/generate_test_annotations.py --question data_2/q00001
```
